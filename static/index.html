Dúvidas Frequentes (FAQ)

                
Esclarecimentos sobre o modelo de tempo e funcionamento das bases.

            

            

                

                    Como funciona o modelo de tempo de acesso?
                    Ao assinar um plano (1h, 12h, 24h, 1 semana ou 1 mês), você ganha acesso ilimitado para realizar pesquisas durante todo o período ativo sem limites de créditos.
                

                

                    E se o bot do Telegram pedir escolha de base (Nome ou CPF)?
                    O sistema exibe na tela um alerta elegante com botões reais das bases retornadas (ex: Simples, Sync, Receita, SI-PNI, Credlink, etc.). Basta clicar no botão desejado para a consulta ser concluída instantaneamente.
                

                

                    Como funciona o usuário teste (Trial)?
                    O usuário de teste conta com 20 minutos de uso gratuito, limite de 20 consultas e um delay de 60 segundos entre cada busca para fins de demonstração.
